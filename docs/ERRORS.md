# Error Register

Tracked defects found during the CI/agent audit begun on 2026-10-24 and continued on 2026-10-25. Status is derived from code and tests, not from assumptions. This file is the in-repo error tracker; the CI job `tests` fails if any of these regressions return.

**Error tracking rule:** every error records *how it happened* (reproduction/observation + root cause) and the *solution path* (fix, why it was chosen, regression test). No invented data.
