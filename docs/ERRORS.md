# Error Register

Tracked defects found during the CI/agent audit begun on 2026-10-24 and continued through 2026-10-26. Status is derived from code and tests, not from assumptions. This file is the in-repo error tracker; the CI job `tests` fails if any of these regressions return.

**Error tracking rule:** every error records *how it happened* (reproduction/observation + root cause) and the *solution path* (fix, why it was chosen, regression test). No invented data.

**Linear:** team `PRO`, project **"BetterCI (VibeCI) - CI Hardening & Error Tracking"**. Issues `PRO-43` to `PRO-50` mirror E-01 and E-03 to E-09 below.
